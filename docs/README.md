# Documentation

We develop and test ramtaskman on Linux and Windows. The macOS backend is
experimental: we don't have a Mac, so we haven't tested or validated it.
Our own testing and CI cover Linux and Windows.

The main README and public guides are in English. Existing document filenames
are retained so links continue to work. The README is also available in nine
other languages, including [Italian](i18n/README.it.md).
