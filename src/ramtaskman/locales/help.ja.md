# ramtaskman · 数値の読み方

gputaskmanの画面構成を、Linux、Windows、macOSのメモリ向けに調整しています。

| 項目 | 意味 |
|---|---|
| PSS | プライベートRAMと、共有ページの比例配分分 |
| USS | Private_Clean + Private_Dirty：プライベートな常駐ページ |
| RSS | 共有ページを含む常駐ページ。合算すると重複することがあります |
| Swap | smaps_rollupのSwap。shmemのスワップを除き、共有ページが重複する場合があります |
| SwapPSS | smaps_rollupが計上する共有スワップの比例配分分 |
| RAM used | MemTotal − MemAvailable。プロセスの合計とは一致しません |
| Cache | Cached + Buffers + SReclaimable − Shmem。利用可能メモリと重複します |
| PSI some | 1つ以上のタスクがメモリを待っている時間の割合。10秒平均 |

**RAMバー：** 全幅を使い、LinuxのOSカウンターを匿名メモリ、ファイルキャッシュ（Cached − Shmem）、共有/tmpfs、バッファ、回収可能/回収不可のslab、その他（計算した残余）、空きメモリに分けます。会計上の分類であり、並び順は物理アドレスではありません。利用可能メモリは回収可能なキャッシュを含む別の指標なので、追加の区画にはなりません。プロセスのclean/dirtyとPSSの詳細は全体のカウンターと重複するため、**d**に表示します。項目が欠けるかサンプルに不整合がある場合、バーは使用中/利用可能を示し、内訳がない理由を表示します。1文字幅未満の分類も凡例に残ります。

**アプリUSSバー：** USSが完全な上位10アプリと、それ以外の完全なアプリを表示します。尺度はそのサンプル内でUSSが完全なアプリの合計であり、システムの総RAMではありません。番号と色は凡例に対応します。不完全なグループは除外し、測定のカバー範囲を明示します。グループ分けは表と同じです。区画は物理アドレスではありません。

**Windows/macOS：** USSとRSSはpsutilから取得します。プロセス別PSS、Swap、SwapPSSは提供されずn/aです。Windowsのプライベートcommit/pagefileはディスク上のスワップではありません。macOSのRAM usedはpsutilのtotal − availableであり、アクティビティモニタのメモリプレッシャーではありません。

**アプリのグループ化：** Linuxでは明示的なsystemd cgroupがアプリのインスタンスを識別します。異なる実行ファイルの補助プロセスも含められます。異なるユーザーとインスタンスは分離します。この識別情報がない場合は、Windows/macOSを含めてユーザー + 実行ファイルを使い、パスが読めなければユーザー + 名前をヒューリスティックとして使います。インスペクターに方法を表示します。

**検索とフィルター：** **/**で名前、実行ファイル、正確なPIDを検索し、**f**でユーザーとメモリ状態（**スワップあり**、**部分データ**）を選びます。条件は組み合わせられます。アプリ内の1プロセスが検索またはメモリ状態に一致するとアプリが一致しますが、合計には全メンバーを残します。プロセス表示に入ってもフィルターは維持します。フィルターは上位30件の制限より先に適用し、グラフとダッシュボードはシステム全体を示します。検索欄で**Enter**を押すと表に戻ります。操作欄の**Esc**または**Reset**はフィルターを消し、プロセス表の**Esc**は条件を維持してアプリに戻ります。部分データはOSが対応するカウンターだけを考慮します。不明なスワップは使用中のスワップを意味しません。

**d**はグループまたはプロセスのRAM詳細を開きます。匿名/ファイル/shmemのPSS、プライベートと共有のclean/dirty、匿名ページ、LazyFree、THPを表示します。Linux専用項目で、ほかのOSではn/aです。各行は重複する見方なので、すべてを足してはいけません。サンプルは開いた時点で固定します。更新するには閉じて開き直してください。**Esc**または**d**で閉じます。

プロセス上の**r**または**Enter**でLinuxの領域マップを開きます。アプリ上の**r**は先にPIDを表示します。各プロセスには独立した仮想空間があります。**d**のバーはPSSとRSSを別々に分け、スワップは常駐RAMに含めません。

マップでは、**v**でRSS/仮想アドレスを切り替え、**s**で並べ替え、**/**でファイルまたは0x…アドレスを検索し、**f**で種類/状態を絞り込みます。**z**または**Enter**は選択領域の近傍を拡大し、**r**は更新、**Esc**はフィルター解除/ズーム終了/戻るです。マップは仮想アドレスの順であり、物理フレームではありません。隙間は仮想尺度から除外し、│で示します。1文字幅未満の領域も表に残ります。種類はマッピングの由来であり、内容ではありません。ファイルにもプライベートCoWページが含まれ、識別できたヒープ/スタックだけをそう呼びます。サンプルは要求時に読み、経過時間、所要時間、読み取り上限を表示します。Windowsは実験的な仮想範囲のみで、macOSには領域マップがありません。

領域表示では**b**でAを固定し、**r**でBを取得、**c**で比較を開きます。比較では**v**が指標、**s**が順序の切り替え、**f**が状態フィルターで、**Ctrl+B**でAを外します。**Ctrl+S**でサンプルを保存し、**Ctrl+O**でファイルをオフライン表示します。ファイルはメタデータを含み、個人のパスが含まれる場合があります。欠損データと再編成された領域はn/aです。同じ区間でも、同じ割り当てやメモリリークの証拠にはなりません。

**n/aはゼロではありません。** アプリ合計は1つでも値が欠けるとn/aです。測定欄はPSS/USSのカバー範囲を示します。ダッシュボードの可視合計は取得できた値の部分和であり、システムの全RAMではありません。読み取りはアトミックではなく、サンプリング中にプロセスが変わる場合があります。他のユーザー、サンドボックス、procfs権限により読めないことがあります。権限は自動昇格しません。ここに表示する通常のRSS/PSS/USSカウンターにHugeTLBは含みません。

プログラムはメタデータを読みます。/proc/PID/mem、cmdline、environment、アプリの内容は読みません。

**g** アプリ/プロセス · **Enter** 選択アプリのプロセス · **Esc** アプリへ戻る

**s** 並べ替え · **c** グラフ · **a** 全件/上位30件 · **m** 簡易/完全

**/** 検索 · **f** フィルター · **d** 詳細 · **r** 領域 · **p** 一時停止 · **?** ヘルプ · **q** 終了

グラフは直近60サンプルを0–100%の尺度で表示します。空白はデータ欠損です。間隔は測定後の待機時間であり、実際の周期にはスキャン時間も含まれます。
