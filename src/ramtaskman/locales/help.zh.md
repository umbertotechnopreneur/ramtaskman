# ramtaskman · 如何理解这些数值

沿用 gputaskman 的界面结构，面向 Linux、Windows 和 macOS 的内存监测。

| 字段 | 含义 |
|---|---|
| PSS | 私有内存，加上按比例分摊的共享页 |
| USS | Private_Clean + Private_Dirty：私有驻留页 |
| RSS | 驻留页，包括共享页；直接相加可能重复计算 |
| Swap | smaps_rollup 的 Swap，不含 shmem 交换空间；共享页可能重复计算 |
| SwapPSS | smaps_rollup 计入的共享交换空间的按比例份额 |
| RAM used | MemTotal − MemAvailable，不等于各进程之和 |
| Cache | Cached + Buffers + SReclaimable − Shmem，与可用内存重叠 |
| PSI some | 至少一个任务等待内存的时间百分比，取 10 秒平均值 |

**内存条形图：** 使用全部可用宽度，将 Linux 操作系统计数分为匿名内存、文件缓存（Cached − Shmem）、共享/tmpfs、缓冲区、可回收/不可回收 slab、其他（计算出的剩余量）和空闲内存。这些是统计类别，排列顺序不代表物理地址。“可用”是另一个指标，包含可回收缓存，因此不是额外的分段。进程的 clean/dirty 和 PSS 详情位于 **d** 视图，因为它们与全局计数重叠。字段缺失或样本不一致时，条形图显示已用/可用内存，并说明无法细分的原因。图例也列出不足一个字符宽度的类别。

**应用 USS 条形图：** 显示 USS 数据完整的前 10 个应用，以及其余完整应用。刻度是本次样本中完整应用的 USS 总和，不是系统总内存。数字和颜色对应图例。部分数据组被排除，并明确显示覆盖情况。分组方式与表格相同；分段不代表物理地址。

**Windows/macOS：** USS 和 RSS 来自 psutil；不提供每进程 PSS、Swap 和 SwapPSS，保留为 n/a。Windows 的私有 commit/pagefile 不等于磁盘上的交换空间。macOS 的 RAM used 是 psutil 的 total − available，不是“活动监视器”的内存压力。

**应用分组：** Linux 上，明确的 systemd cgroup 标识应用实例，即使辅助进程使用不同的可执行文件，也可以属于该实例。不同用户和实例保持分离。缺少此标识时（Windows/macOS 也如此），使用“用户 + 可执行文件”；路径不可读时，以“用户 + 名称”作为启发式分组。检查面板会说明所用方法。

**搜索和筛选：** 按 **/** 搜索名称、可执行文件或精确 PID；按 **f** 选择用户和内存状态（**有交换空间**或**部分数据**）。筛选条件可以组合。应用的任一进程匹配搜索或内存状态时，该应用就匹配，但总计仍保留全部成员。进入进程视图后保留筛选条件。筛选在前 30 条限制之前生效；图表和仪表板描述整个系统。从搜索框按 **Enter** 返回表格。在控件中按 **Esc** 或 **Reset** 清除筛选；在进程表格中按 **Esc** 返回应用视图并保留筛选。“部分数据”只考虑系统支持的计数；未知交换量不意味着已使用交换空间。

**d** 打开所选组或进程的内存详情：匿名/文件/shmem PSS、私有和共享 clean/dirty、匿名页、LazyFree 和 THP。这些细分字段仅 Linux 提供，其他系统为 n/a。各行是重叠的视角，不能全部相加。详情在打开时固定样本；关闭并重新打开可刷新。按 **Esc** 或 **d** 关闭详情。

在进程上按 **r** 或 **Enter** 打开 Linux 区域地图。在应用上按 **r** 会先显示 PID：每个进程都有独立的虚拟地址空间。**d** 中的条形图分别细分 PSS 和 RSS；交换空间不属于驻留内存。

区域地图中，**v** 切换 RSS/虚拟地址，**s** 排序，**/** 搜索文件或 0x… 地址，**f** 按类型/状态筛选，**z** 或 **Enter** 放大所选区域附近，**r** 刷新，**Esc** 依次清除筛选、退出缩放或返回。地图按虚拟地址排列，不表示物理页框。间隙不计入虚拟刻度，用 │ 标记；宽度不足一个字符的区域仍可在表格中选择。类型表示映射来源，不表示内容：文件映射可能包含私有 CoW 页；只有识别出的堆和栈才这样标注。样本按需读取，并显示采样年龄、持续时间和读取限制。Windows 仅提供实验性的虚拟区间；macOS 不提供区域地图。

在区域视图中，**b** 固定 A，**r** 采集 B，**c** 打开比较。在比较视图中，**v** 切换指标，**s** 切换排序，**f** 筛选状态，**Ctrl+B** 移除 A。**Ctrl+S** 保存样本；**Ctrl+O** 离线打开文件。文件包含元数据，可能包括个人路径。缺失数据和重组后的区域保留为 n/a；相同区间不能证明是同一次分配，也不能证明内存泄漏。

**n/a 不等于零。** 应用总计中只要缺少一个值，就显示 n/a。“读取”表示 PSS/USS 覆盖情况。仪表板中的可见总计只是可读取数据的部分和，不代表系统全部内存。读取不是原子的，进程可能在采样期间变化。其他用户、沙箱和 procfs 权限可能阻止读取。程序不会自动提升权限。这里普通的 RSS/PSS/USS 计数不包含 HugeTLB。

程序只读取元数据，不读取 /proc/PID/mem、cmdline、environment 或应用内容。

**g** 应用/进程 · **Enter** 所选应用的进程 · **Esc** 返回应用  
**s** 排序 · **c** 图表 · **a** 全部/前 30 条 · **m** 精简/完整  
**/** 搜索 · **f** 筛选 · **d** 详情 · **r** 区域 · **p** 暂停 · **?** 帮助 · **q** 退出
